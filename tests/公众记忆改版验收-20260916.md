# 公众记忆改版验收 · 2026-09-16

- 基线：5bd73a2；前端版本：20260916-memoryfeed04。
- 首页入口改为公众记忆，双列图片帖子，点击读正文、放大照片、点赞，地点下拉筛选。手机独立全屏。
- 采用表达偏好整理稿的记录只展示采用后的正文；未采用的稿不展示。原文及审核记录继续保存。移除重复原文/整理稿、材料类型及卡片审核标签。
- 投稿三步：真实记忆与表达偏好 → 地点与照片 → 最后确认使用授权并投稿。草稿以浏览器身份隔离，本地保存文字及表达选择，不保存授权勾选；重开需重选照片。
- 照片选择追加、取消保留、重复排除、最多三张、逐张删除；失败后保留当前文字和照片。配图明确标注，不计入真实投稿照片。
- 我的记忆可按总数、审核中、已公开、点亮筛选，可放大照片；未通过记录保留。
- 点位详情增加分类下拉选择，现有四类列表滚动，不隐藏其他地图点位。官方介绍集中显示，历史导读展开。
- 新增望江楼公园（薛涛井）。古图原图 2400×2049 的井形符号中心约 (1647,1570)，百分比 (68.625,76.623)，仅古图阅读锚点。原25点数据不改。
- 园方来源：https://www.wangjianglou.com/about.html 和 https://www.wangjianglou.com/build/201804/178.html 。
