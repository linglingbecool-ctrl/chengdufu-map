# 公众记忆点赞与排序（2026-09-11）

已实现：每条公开记忆支持点赞/取消点赞；同一云端身份只计一赞。每个点位的文字、图文列表各自按赞数降序排列，同赞数按投稿 ID 保持固定顺序。点赞后保持当前卡片附近的阅读位置。匿名浏览器可用；匿名身份不是实名人数，清除浏览器数据或换浏览器会形成另一个身份。

数据：memoryLikes 和 memoryLikeTotals 均已创建并回读确认 ADMINONLY。用户不能直接写票数。setMemoryLike 从云端身份取 UID，检查 approved、consentToPublish、rightsConfirmed 三个条件，在同一事务中保存点赞记录与总数。按目标状态写入，网络重试不重复计票。赞数独立于投稿，保留原文、照片和审核状态。

部署：setMemoryLike、getPublicMemories 已部署。2026-09-11 实际调用公开列表返回 23 条、ok=true，均有有效点赞字段，调用耗时 128ms；没有读者身份的点赞请求被拒绝为 NOT_LOGIN。测试未对真实投稿添加赞。
