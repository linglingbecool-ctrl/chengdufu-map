# Chengdu map labels

`chengdu-map-kai.woff` is a web-only subset of LXGW WenKai TC Regular (Google Fonts v11), containing the modern labels in `points.json`. The internal family name is Chengdu Map Kai. No glyph outlines were altered.

- Original project: https://github.com/lxgw/LxgwWenKaiTC
- Font distribution: https://fonts.google.com/specimen/LXGW+WenKai+TC
- License: `OFL-LXGW-WenKai.txt` (SIL OFL 1.1).
- Downloaded 2026-10-28 via Google Fonts CSS2 text subsetting, then converted to WOFF with fontTools.

When adding or renaming a point, regenerate this small subset from all modern point names. Unsupported new characters fall back to system Kai/serif fonts.
